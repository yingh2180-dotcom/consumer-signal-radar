## 2. 视觉核对
已用 view_image 查看 design/concept.png、outputs/dashboard.png、outputs/demo_02.png、outputs/mobile.png；实际浏览器截图来自已安装的 Edge，因为当前没有内置浏览器工具且 Playwright Chromium 未安装。

| 检查点 | 结果及取舍 |
|---|---|
| 页面结构 | 保持侧栏、四项统计、三页签、双图、证据详情的顺序 |
| 背景与颜色 | 纯白主区、浅灰侧栏、青绿指标和图表、深蓝文字，与参考体系一致 |
| 字体层级 | 修正原生三级标题过大问题；主标题与次级标题分层 |
| 证据内容 | 卡片显示真实数据行 ID 和原文；混合簇显示组合话题，避免单一标题误导 |
| 控件与文案 | 采用原生 Streamlit 上传/表格/筛选；新增必要分析入口和参数；设计占位数字全部替换为实际计算值 |
| 响应布局 | 窄屏改为单列，侧栏可折叠；无需缩小到不可读字体 |

这是按参考视觉体系实现的 Streamlit Demo，不声称像素级复刻或用户已认可设计。原生控件、额外方法说明、动态数据、较长证据让页面高于参考图，属明确保留差异。未增加营销效果或品牌事实声称。

## 3. 发现并修复
首次页面运行发现 pandas 的 product 方法与同名字段冲突，改用显式列访问；已通过页面与上传复验。首次浏览器脚本对原生下拉框内部文本定位不稳定，改为按控件标签定位并通过。证据阅读时发现簇内混合话题，改用组合标题而非只取最多的话题。
