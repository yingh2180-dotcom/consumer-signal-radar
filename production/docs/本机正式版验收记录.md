## 4. 视觉核对

实际页面保持参考稿的白色主区、浅灰工作台、深蓝正文、青绿色图表和操作色、左侧导航、四项统计、双图表及证据详情结构。正式版将导入、任务、报告和设置拆成独立页面，这是完整工作流要求带来的结构扩展。

最新版机会卡明确展示：样本事实、待验证假设、建议验证方式、原文证据和结论边界。合成数据提示保持醒目，没有使用设计稿中的占位数字冒充计算结果。

- 补齐缺失的 `styles.css`，修复生产构建阻塞。

- 统一前后端项目名称最大长度为 100。
- 字段映射中禁用已被其他字段选择的源列。
- 原文搜索支持文本与编号；导入质量文案与后端字段一致。
- 报告和机会卡增加数据来源、分析方法、事实、假设、验证方案及边界说明。

- 增加内嵌站点图标，消除 favicon 404。
