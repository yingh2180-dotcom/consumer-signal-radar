## 3. 四层测试

1. 单元测试：验证去重、评分、预算、备份等单个规则。
2. 接口测试：验证登录、项目、导入、任务、洞察和报告 API。
3. 端到端测试：从用户点击开始，验证完整业务链路。
4. AI 质量评测：用人工金标衡量字段抽取准确性。

前面三层通过只能证明软件流程可用，不能代替第四层的模型质量结论。

## 4. 本机复验步骤

### 自动化测试

在 production 目录使用项目虚拟环境运行测试。若依赖已安装，执行：

~~~powershell
..\.venv\Scripts\python.exe -m unittest backend.test_engine backend.test_server backend.test_runtime -v
~~~

预期结果：22 项测试全部通过，无外部模型请求。

### 前端构建

在 production/frontend 目录执行：

~~~powershell
npm.cmd run build
~~~

预期结果：生成 dist，命令成功退出。

## 5. AI 质量评测

### 准备金标

- 从有权使用的数据中抽取至少 100 条。
- 先写标注规范，再由人工标注。
- 对分歧进行复核，形成最终标准答案。
- 测试集与提示词调试集分开。

### 计算指标

- Precision：模型提取出的结果中有多少是对的。
- Recall：应该提取的结果中有多少被找到了。
- F1：综合 Precision 与 Recall。

对产品、反馈类型、维度、场景、成分、情感和严重程度分别计算，不用一个平均数掩盖弱项。关键字段 F1 全部达到 0.80 后才能通过该验收。

### 失败后的处理

保存错误样本，区分漏提取、误提取、标签边界不清、JSON 失败和来源文本不足；只在调试集上改提示词，再对未见过的测试集重新评测。
