# Consumer Signal Radar 操作说明书

## 1. 变更定位

- 新增文件：production/docs/03_操作说明书.md
- 适用对象：第一次使用本项目的面试展示者、产品经理和分析师。
- 当前入口：http://127.0.0.1:18522/

## 2. 使用前准备

1. 双击 production/启动正式版.cmd。
2. 等待浏览器打开登录页。
3. 从本机 production/.env 查看管理员密码。不要把密码或 API Key 发到聊天或截图中。
4. 先使用“离线规则”模式完成演示，真实模型需另行配置。

如果页面未自动打开，手动访问上面的本机地址。本机地址仅供当前电脑访问，不是公网链接。

## 3. 十分钟完整演示

### 第一步：登录

输入管理员密码并登录。失败时检查是否多输入空格、服务是否仍在运行。

### 第二步：创建项目

点击“新建项目”，名称可填“双抗精华消费者反馈演示”，描述可填“用于展示评论结构化、主题洞察和证据回溯”。项目是一次独立研究的容器。

### 第三步：导入数据

初次演示选择“导入合成演示样本”。系统会明确标记这些内容是合成数据，只用于验证流程。

导入自己的文件时：

- 支持 CSV、XLSX。
- 必须有评论正文。
- 推荐包含产品、品牌、日期、平台、原文链接和原始编号。
- 先看预检，再确认入库。
- 错误行应先记录原因，修复后重新导入。

### 第四步：创建分析任务

进入“分析”，选择刚导入的批次，分析模式选“离线规则”，提交任务。页面会显示等待、运行、完成或失败。

### 第五步：阅读洞察

进入“洞察”，依次查看样本量与来源状态、痛点排行、趋势、机会卡和原始证据。机会分只用于排序，先看样本事实，再看待验证假设和验证建议。

### 第六步：复核证据

打开机会卡证据，核对原文、平台、日期和产品，再标记为“通过、驳回或待定”。人工复核只说明该证据被检查，不代表整批来源真实性已经审核。

### 第七步：保存和下载报告

进入“报告”，保存当前结果并下载 Markdown。报告应包含数据类型、来源状态、样本数、去重数、分析方式、证据和限制。

## 4. 使用真实模型

只有准备好本机 API Key 并愿意消耗已确认的 20 元预算时才操作：

1. 登录网页后，点击右上角“模型配置”。
2. 在密码框中填写百炼 API Key；填写服务地址、文本模型和向量模型。
3. 按需勾选“允许真实模型计费调用”，然后点击“保存模型配置”。API Key 保存后会从输入框清空，网页和接口均不会回显原文。
2. 在本机 .env 中填写 RADAR_API_KEY。
3. 确认模型名和接口地址。
4. 将 RADAR_PAID_ENABLED 设置为 true。
5. 重启服务。
6. 先导入约 20 条有权处理的评论。
7. 选择真实模型模式运行。
8. 检查费用、错误、结构化结果和证据，再决定是否扩大样本。

不要把 Key 写进代码、文档、截图或聊天。联调前按官方文档核对当日模型名称和价格。

## 5. 自有数据格式

| 字段 | 必填 | 示例 |
|---|---|---|
| text | 是 | 上脸有点烫，后面没有持续泛红 |
| product | 否 | 双抗精华 |
| brand | 否 | 珀莱雅 |
| date | 否 | 2026-08-01 |
| platform | 否 | 公开电商评价 |
| source_url | 否 | 原文公开链接 |
| id | 否 | source-001 |

缺少日期的评论可进入总体统计，但不能可靠进入趋势分析。只导入公开、获授权或合成内容。

## 6. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 页面打不开 | 重新启动并检查 18522 端口 |
| 登录失败 | 从本机 .env 核对密码 |
| 文件无法导入 | 检查格式、编码和正文列 |
| 导入后数量变少 | 系统去除了重复评论 |
| 任务一直等待 | Worker 可能未启动，重启并查看日志 |
| 没有机会卡 | 有效负面或混合证据可能不足 3 条 |
| 真实模型不可选 | Key、付费开关或预算条件未满足 |
| F1 没有达标结果 | 尚未导入至少 100 条独立人工金标 |
| Docker 无法启动 | 当前容器路径尚未正式验收，先用本机脚本 |

## 7. 正确关闭

关闭浏览器不会自动结束服务。演示结束后使用项目提供的停止入口或关闭对应启动窗口。任务运行时先等待完成，再做备份或恢复。

## 8. 推荐演示话术

“当前展示的是本机已验证的完整产品流程，数据为合成演示样本；真实模型、授权真实数据和 100 条人工金标评测是下一阶段验收项，因此当前结果不代表真实市场结论。”
## 2026-09-09 账号功能变更定位

- 新增：用户名密码注册、注册后自动登录、管理员登录入口、系统样本复制与私人数据隔离。

### 账号注册与登录

1. 打开工作台，在登录页选择“注册”。
2. 输入 3–32 位用户名和 8–128 位密码，再次确认密码。
3. 点击“注册并进入”，成功后会自动登录。
4. 以后选择“登录”，输入相同用户名和密码即可进入；刷新、退出或重启服务不会删除账号和私人数据。
5. 需要维护模型 API 时选择“管理员登录”，使用本机管理员密码。

所有账号都能看到带“系统样本”标识的演示项目。系统样本只读；点击“复制到我的项目”后，会生成只属于当前账号的副本。不同账号不能看到彼此的私人项目和数据。
