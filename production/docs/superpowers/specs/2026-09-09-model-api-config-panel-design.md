# 模型 API 配置面板设计

## 1. 变更定位

- 目标界面：Consumer Signal Radar 登录后的全局顶部栏。
- 操作类型：新增模型配置入口、可缩小悬浮窗口和相关状态说明。
- 不改变：分析算法、模型调用流程、预算熔断和 API Key 服务端存储方式。

## 2. 用户目标

用户无需进入深层设置页，就能看懂项目需要哪些模型、当前是否已配置、怎样获得 API Key，以及为什么真实模型仍不可使用。

## 3. 采用方案

在顶部栏增加“模型配置”按钮：

- 未完成配置时显示橙色状态点和“待配置”。
- 完整配置且允许付费时显示绿色状态点和“已启用”。
- 已配置但付费关闭时显示蓝色状态点和“已配置”。

点击后从右侧打开悬浮面板。面板支持：

- 关闭：完全隐藏；
- 缩小：收为页面右下角的小浮窗；
- 还原：从小浮窗恢复完整面板。

## 4. 面板内容

### 4.1 当前状态

读取现有 GET /api/settings，只展示：

- 文本模型名称；
- 向量模型名称；
- API 配置是否完整；
- 付费调用是否开启；
- 单次导入上限；
- 20 元预算说明。

前端不会读取或显示 API Key。

### 4.2 模型清单

| 类型 | 必需性 | 推荐模型 | 用途 |
|---|---|---|---|
| 文本模型 | 必需 | qwen3.5-plus | 评论结构化抽取与口语语义理解 |
| 向量模型 | 必需 | text-embedding-v4 | 评论向量化与探索性聚类 |
| 重排模型 | 当前不需要 | qwen3-rerank | 未来语义检索结果二次排序 |

同时说明 qwen-turbo 可作为低成本文本模型备选，但切换后必须重新做金标评测。

### 4.3 获取和配置路径

面板提供三个明确动作：

1. 打开阿里云百炼 API Key 官方说明；
2. 打开百炼模型价格官方页面；
3. 提示双击本机配置.cmd，在服务器端 .env 中填写配置。

界面不提供 API Key 输入框，避免密钥进入浏览器状态、截图或前端日志。

## 5. 交互状态

- 打开：点击顶部“模型配置”。
- 缩小：点击面板标题栏的缩小按钮。
- 还原：点击右下角“模型配置”浮窗。
- 关闭：点击关闭按钮或遮罩。
- 键盘：按 Escape 关闭完整面板。
- 移动端：面板占据屏幕大部分宽度；缩小浮窗不遮挡底部主要操作。

## 6. 组件边界

- ModelConfigPanel：完整悬浮面板。
- ModelConfigLauncher：顶部入口和状态。
- ModelConfigMini：缩小状态。
- App：只管理 open、minimized、closed 三种显示状态。
- GET /api/settings：继续作为唯一配置状态来源，不新增密钥接口。

## 7. 错误处理

- 设置接口失败：入口显示“状态未知”，面板解释需要检查本机服务。
- 缺少模型名或 Key：显示待配置，不允许暗示可调用。
- 付费关闭：显示配置已检测但真实调用未开启。
- 官方链接打不开：不影响本机离线模式。

## 8. 验收标准

- 顶部入口在登录后所有页面可见。
- 点击入口能打开面板。
- 缩小、还原、关闭均可操作。
- 状态文案与 /api/settings 返回值一致。
- 页面和浏览器源代码中不出现真实 API Key。
- 桌面与 390 像素宽页面无横向溢出。
- 原设置页仍可使用。
- 前端生产构建通过。
- 浏览器验证入口、面板、缩小、还原、外链和移动端状态。

## 9. 当前事实边界

- 项目当前默认配置文本模型 qwen3.5-plus、向量模型 text-embedding-v4。
- 当前页面只能展示服务端是否完成配置，不能替用户创建 Key。
- 真实模型尚未完成本项目质量验收。
- 模型名称、价格和地域能力可能变化，最终以百炼官方页面为准。
