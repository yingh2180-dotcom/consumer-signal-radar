> 第一次接触项目，请从 [项目学习导航](docs/00_项目学习导航.md) 开始。导航依次连接 PRD、技术架构、操作、工作流、ADR、测试验收、面试讲解和开发维护文档。


## 1. 变更定位

- 本文是 `production/` 本机原生版的启动、使用和验收入口。
- 当前已通过离线完整流程与本机浏览器验收；真实百炼模型、真实数据 F1 和 Docker 仍按第 6 节标注为待验证。
- 旧版 Streamlit Demo 保留在上级目录，不作为本正式版的验收依据。

## 2. 一键启动

双击 [启动正式版.cmd](启动正式版.cmd)。程序会启动 API 与后台分析进程，并打开：

<http://127.0.0.1:18522>

该地址只在本机访问，不是公网发布。首次配置文件已生成；管理密码保存在 `.env`，不要把该文件、密码或 API Key 发到聊天或提交到公开仓库。

如果更换电脑，需要先准备 Python 环境、安装 `backend/requirements.txt`，并在 `frontend/` 执行 `npm install` 与 `npm run build`。当前电脑已经完成这些准备。

## 3. 面试演示建议流程

1. 使用本机管理密码登录。
2. 新建一个研究项目。
3. 在“数据”页点击“导入合成演示样本”，或上传有权使用的 CSV/Excel。
4. 在“分析”页选择批次，以“离线规则”创建任务。
5. 进入“洞察”页查看痛点排行、反馈趋势和原文证据。
6. 阅读“样本事实、待验证假设、建议验证方式和结论边界”，再勾选人工复核。
7. 保存报告，在“报告”页阅读并下载 Markdown。
8. 在“效果评测”页下载空白标注表；没有真实人工标注时，不展示为 F1 达标。

合成数据必须一直说明“只验证产品流程，不代表真实消费者反馈或珀莱雅业务结论”。

## 4. 数据格式

CSV/Excel 至少包含评论正文列。推荐字段：

| 字段 | 含义 |
| --- | --- |
| `text` | 评论正文，必填 |
| `brand` | 品牌；缺失时保留为未指明 |
| `product` | 产品名称 |
| `date` | 建议使用 `YYYY-MM-DD` |
| `platform` | 来源平台 |
| `source_url` | 原文链接，可选 |
| `id` | 原始记录编号，可选 |

单次导入最多 5000 行。数据持有人负责确认内容来源、使用授权和个人信息处理范围。

## 5. 真实模型配置

双击 [本机配置.cmd](本机配置.cmd) 编辑本机 `.env`：

- `RADAR_API_KEY`：百炼 Key，只保存在本机。
- `RADAR_MODEL=qwen3.5-plus`。
- `RADAR_EMBEDDING_MODEL=text-embedding-v4`。
- `RADAR_PAID_ENABLED=true`：只有准备进行已授权的真实调用时才开启。
- `RADAR_BUDGET_CNY=20`：当前已确认的累计预算上限。

首次真实联调先用约 20 条有权处理的评论。预算记录是项目侧保守限制，实际费用仍以服务商账单为准。

## 7. 备份和恢复

备份业务数据库时使用 `maintenance.py backup --destination <全新目录>`；恢复只允许写入全新目录。备份明确排除 API 预算账本，恢复也会拒绝包含预算账本的旧备份，防止通过恢复历史数据重置已发生的预算记录。

执行备份或恢复前先停止正在写入数据的服务，并保留原 `.env`。密钥不会进入业务备份。
