# 看板设计与审核

## 变更定位
初始 v0.1：新增看板参考、实现取舍和审核检查点。配合 outputs 中实际截图核对。

## 1. 界面规范
参考：concept.png，1536 × 1024。纯白主背景 #FFFFFF、浅灰侧栏 #F6F8FA、深蓝正文 #122239、青绿色操作与图表 #008D95、灰色边框 #DCE2E8。标题约 34px，正文 16px，次级说明 14px；使用系统中文字体。边框容器圆角约 7px。侧栏承担导入与筛选，主区顺序固定为标题、数据提示、四项指标、三个页签、两张图表、机会详情及导出。

## 2. 有意保留的实现差异
用户指定 Streamlit，因此保留其原生文件上传、侧栏折叠、表格和移动端行为，不重写框架控件。参考图中的 120 条/48% 等值是设计占位，实际界面必须由 1000 条样本计算；禁止为视觉一致伪造指标。参考中的机会正文未被用作业务分析，改为证据约束的研究假设。增加真实工作流必须的“开始分析”、簇数、人工命名及导出 Markdown 按钮。

## 3. 概念来源
使用内置 image_gen 生成 UI 参考，不依赖外部模型密钥。最终提示词要点：完整中文 Streamlit 消费者洞察看板、左侧 CSV 上传与模式/品牌/产品/日期、纯白与青绿、四项统计、机会/原文/评测页签、排行与日期趋势、至少三条带 ID 的证据、醒目合成数据说明、无装饰图片。

## 4. 审核基线
执行前已列出上级文件：只有简历和证书等文件，无“消费者洞察”目录。项目由 New-Item -ErrorAction Stop 新建成功，以不存在该目录作为本次变更前基线；本轮未覆盖或修改上级文件。仅本项目属于待审核范围。
